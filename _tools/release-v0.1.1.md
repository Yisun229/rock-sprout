# v0.1.1 · 好管

## 这一版能做什么

- **批量装、批量卸**：矿脉和背包都能多选（点复选框、Shift 连选、Ctrl+A 全选、Esc 清空）。
  一次勾几个一起装，底部会常驻一条进度条：谁在下载、谁在写进游戏、谁没成、为什么没成。
  没成的可以单独重试，成了的不会被拖回去。
- **卸载前先问一句**：批量卸载会先弹一个框，把要删的名字和数量逐个列出来，确认了才动手。
- **看得出谁盖了谁**：背包里每条 mod 会标「被覆盖」或「盖了 N 处」，点开「看看谁盖了谁」
  能看到具体是谁盖了谁；顶部还有「只看有冲突的」开关。
- **装之前先提醒**：一次装好几个时，如果会盖掉已经装的东西，会先汇成一条确认框，
  写清会发生什么，再决定装不装。
- **同一个 mod 不会重复记两条**：本地 mod 的编号改成按文件内容算，同一个文件换个路径导进来还是那一条；
  以前留下的旧记录会在启动时自动整理一次（整理前会留一份备份）。
- **文件没了的记录会标灰**：原文件被删掉之后，那条记录会灰显，按钮变成「仅删除记录」，
  不再试图去动游戏里的文件。

## 用之前要知道

- 只支持 Steam 版《深岩银河》。
- 要能访问 mod.io（这台机器上如果开着本地加速工具，也能用）。
- 令牌从 <https://mod.io/me/access> 自取，粘进设置页；只存在本机，不会上传到别处。
- 装 mod 会改游戏目录里的两个文件：合并包 `FSD\Content\Paks\mods_P.pak` 和加载器
  `FSD\Binaries\Win64\x3daudio1_7.dll`。第一次装的时候会把游戏自带的加载器备份一份，
  卸载时换回去。
- 安装包没有代码签名，Windows 会弹 SmartScreen 提示，点「更多信息 → 仍要运行」。

## 已知不足

- 还没下载过的 mod：装之前算不出它会跟已装的撞哪些文件，只能等下载完、装好之后，
  在背包里靠徽章看结果。本地文件与已经下过的 mod 预检是准的。
- 断网时能看上次抓到的列表、能导入本地 mod、能卸载、能导出配置；但搜不到新东西。
- 检查新版 / 自动更新还没做。

## 校验

`SHA256SUMS.txt` 里是安装包的 SHA-256，下载后可以对一下：

```text
certutil -hashfile RockSprout_0.1.1_x64-setup.exe SHA256
```
