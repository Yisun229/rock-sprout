# 岩笋 · RockSprout v0.1.8

《深岩银河》的 mod 管理器。装、卸、体检都在你自己电脑上做，不替你上传任何东西。

这一版是「打磨」：不添新功能，把宽屏、键盘、文档、治理这几件该做没做的事做完。

## 这一版修了什么

- **点链接不会再把你关在应用里。** 以前点「怎么拿令牌」那个网址，整个窗口会变成网页、还回不来；现在一律交给系统浏览器打开，窗口原地不动，底部给一行「已在浏览器打开」，2 秒自己消失。同时给主窗口加了导航拦截——除了应用自己的页面，任何地址都会被挡下并转交浏览器，以后再有漏网的链接也不会把界面弄丢。
- **宽屏不再大片留白。** 列表页（矿脉、背包、今天）铺满整宽，多出来的宽度给「名字 + 简介」列；设置页这种表单页限宽 860 并居中；右侧抽屉宽度跟着窗口走（`clamp(320px, 32vw, 520px)`），内容区的让位跟着算，不会盖住列表。
- **键盘能用。** 整张列表是一个 Tab 停靠点，进去以后 ↑/↓ 换行、Enter 开抽屉、Esc 关掉并把焦点送回搜索框。装了 mod 以后，背包页会自己刷新，不用手动点「刷新」。
- **同一时间只允许开一个窗口。** 两个窗口同时改合并包会把游戏目录弄坏，现在第二个会提示「岩笋已经开着了」然后自己退出。
- **修了两个只在特定顺序下才露头的 bug**：批量卸载两条时偶发「拒绝访问」，以及脚本类 mod 的状态被全局覆盖成同一个值。
- **文档与治理**：README 补了「两条规则」（数据目录三级回落、版本号规则）和治理一节（怎么提 issue、怎么报安全问题、名字与图标的使用边界、贡献流程）；许可证顶部加了版权行。

## 已知限制

- **合并包被外部程序占用时**：极端情况下（杀毒软件、搜索索引、网盘同步正在扫这个文件夹），合并包写不进去。程序会重试 3 次，然后明确告诉你是哪个文件被占着、关掉什么再试——**不会静默卡住**，你的 mod 和游戏目录也不会被动过。
- **官方 UE4SS 不支持为 UE4SSL 编译的 C++ 脚本 mod**。这类 mod 装进去 UE4SS 会报「缺一个运行库」（`0x7e`），那不是安装坏了，是那个 mod 要的环境我们没有。Lua 脚本 mod 不受影响。
- **在中国大陆用，需要自备网络条件**。mod.io 官方服务器在大陆访问不稳定，多数时候得先把自己的网络条件弄好才连得上。连不上不是程序坏了，也不是令牌失效。

## 用之前

- Windows 10 / 11，64 位。
- 需要 WebView2 运行时（Win11 自带，Win10 多数也有；缺了程序会自己提示并给出下载地址）。
- 电脑要能访问 mod.io。
- 「装 mod」会改游戏目录里的两个文件：`FSD\Content\Paks\mods_P.pak` 和 `FSD\Binaries\Win64\x3daudio1_7.dll`。第一次装之前会把游戏原版备份到数据目录，卸载时放回去。

## 下载哪个

- **安装版**：`RockSprout_0.1.8_x64-setup.exe`。装到当前用户目录，不弹 UAC；卸载不动你的数据。
- **便携版**：`RockSprout_0.1.8_portable_win64.zip`。解压到能写的地方双击 `RockSprout.exe`，数据和令牌就在同目录的 `data\` 里，整个文件夹拷走就是换机。

Windows 可能弹 SmartScreen（「Windows 已保护你的电脑」）——这个包没有代码签名证书，点「更多信息」→「仍要运行」。
