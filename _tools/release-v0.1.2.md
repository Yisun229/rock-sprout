## 这一版能做什么

v0.1.2 的主题是「敢用」——装 mod 难免出岔子，这一版的重点是**出岔子之后能退回来**。

### 新东西

- **装之前自动留现场**：每次装、卸、导入之前，自动把「合并包 + 装了哪些 mod」存一份（一份 2–5 MB，自动只留最近 3 份）。
- **手动保存点**：设置页「装坏了能退回来」里可以自己存一个点，存下的不会自动清理。
- **一键退回**：点「退回到这里」，合并包和已装列表一起退回去。退回之前还会先拍一份「回滚前」，退错了还能再退回来。
- **合并包原子写**：先写 `mods_P.pak.tmp`，校验条目数通过才换上正式名字。中途断电、崩溃、磁盘满，游戏目录里不会留下半截包——要么是旧的，要么是新的。
- **装之前先看游戏有没有开着**：开着就直说「《深岩银河》正在运行，请先关掉游戏再操作」，不再让你看 `os error 32`。
- **游戏更新过会提醒**：记着主 pak 的大小和修改时间，对不上就提示「游戏本体好像更新过，得重装一次 mod」，同时把「退回到这里」按灰（旧快照是上一版游戏的数据，硬退回去等于投毒）。
- **体检**：设置页一键查「该在的不在、不该在的还在」——残留的临时文件、加载器状态、记账有文件没了、下载目录里没人认领的文件、游戏目录里别的工具留下的 pak。能处理的给按钮，处理都是「挪进备份目录」，不删你的东西。

### 要求

- **Steam 版《深岩银河》**（Xbox / Game Pass 版目前不支持）。
- 能访问 `api.mod.io`，并有一个 mod.io 个人访问令牌（在 <https://mod.io/me/access> 生成，粘一次就记住）。
- 装 mod 时会改游戏目录里的两个文件：`FSD\Content\Paks\mods_P.pak` 和 `FSD\Binaries\Win64\x3daudio1_7.dll`。**第一次装的时候会把游戏原本那个 DLL 备份到本程序的数据目录**，卸载时会换回去。

### 安装

下载 `RockSprout_0.1.2_x64-setup.exe` 双击安装即可。安装包没有代码签名，Windows 可能会弹 SmartScreen 提示——点「更多信息 → 仍要运行」。

同一页有 `SHA256SUMS.txt`，想核对文件完整性可以用它。

### 已知不足

- 没有 mod 详情页，看简介只能在列表里看一行。
- 下载显示不出百分比进度，只有「正在下载」。
- 不会自动检查新版（要自己来 Releases 看）。
- 体检处理陌生产物时会**挪走**而不是删，挪走之后游戏目录里就少一个包——如果你确实在用别的工具，别点那一下。
- 中文界面，没有多语言。
