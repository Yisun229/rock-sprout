# 岩笋 · 品牌与 UI 设计

> 配套：`路线图-v0.1到v1.0.md`、`v0.1-任务清单.md`
> 定位：深岩银河的随身伴侣。装 mod 只是它的第一件事。
> 记录时间：2026-10-27

---

## 0. 产品定义

**不是启动器。** 名字叫岩笋没问题，问题在"启动器"这个品类词。

**一句话**：**装进去，看出来。**
- 装进去：把外来的 mod 合并进游戏的资源包（v0.1–v1.0）
- 看出来：把游戏里的数据读出来看（v1.1–v2.0）

| 项 | 定 |
|---|---|
| 品类名 | 深岩银河伴侣 / DRG Companion |
| 产品名 | 岩笋 / Rock Sprout |
| 口语 | 可以叫"岩笋"，别说"岩笋启动器" |

**是什么**：装 mod 的工具 / 看数据的工具 / 完全免费开源的本地软件 / 只服务一款游戏

**不是什么**：Steam 替代品（不买、不下载游戏本体）/ 账号系统 / 社区论坛 / 云服务 / 多游戏平台

**为什么不用"启动器"**：

1. **承诺过重**——启动器要管游戏库、下载、更新，我们只能兑现"启动"这一项
2. **市场位置重复**——Steam 已经是启动器了，第二个没有意义
3. **品牌风险（最要紧的一条）**——中文语境里"启动器"常和"免 Steam 版""绕过平台"联想在一起，容易被误会成盗版工具

---

## 1. 一句话

**岩笋 —— 长在岩层里的笋，陪你把深岩银河挖透。**

- 竹笋：破土、层叠、一节一节往上长
- 岩层：深岩银河全在地下，洞穴里本来就有石笋
- 合起来就是：**从岩石里冒出来的小东西**，正好是一个"伴随游戏生长"的工具

---

## 2. 名字

| 中文 | 英文 | 一句话 | 问题 |
|---|---|---|---|
| **岩笋** ⭐ | Rock Sprout / Sprout | 长在岩层里的笋 | 需要解释一次，但一次就够 |
| 石笋 | Stalagmite | 洞穴里的笋，最贴游戏 | 英文太长，念不清 |
| 竹节 | Cane | 一节一节往上长，对应 v1.1→v1.6 | 和游戏没关联 |
| 春笋 | Spring Shoot | 雨后春笋，mod 越来越多 | 听着像农产品 |

**选定：岩笋 / Rock Sprout**

### 2.1 写法规范

| 场景 | 写法 | 说明 |
|---|---|---|
| 关于页、窗口标题、文档标题 | **岩笋 · Rock Sprout** | 中文在前，`·` 分隔，前后各一个空格 |
| 品类副标（只能出现一处） | 深岩银河伴侣 · DRG COMPANION | 全大写只给品类，不给产品名 |
| 界面内、口语 | 岩笋 | 不提英文 |
| GitHub 仓库 / 包名 / 域名 | `rock-sprout` | 一律小写连字符 |
| 可执行文件 | `sprout.exe` | 短，好打字 |
| 图标 / favicon | 只用图形 | 不带字，小尺寸才认得出 |

### 2.2 排版规则（"高级感"的真正来源）

英文本身不产生高级感，**规整的层级**才产生。三条：

1. **英文永远比中文小一号、轻一档**（字号 −2，字重 −1）
2. **字距**：英文加 `0.02em`，中文不动
3. **颜色**：中文用笋白 `#E8DFCB`，英文用 60% 透明度

### 2.3 五个不要

- 不要 `ROCK SPROUT` 全大写当主名（像免责声明，不像品牌）
- 不要中文后加括号 `岩笋（Rock Sprout）`（像注释；`·` 才像联名）
- 不要音译成 `Yan Sun` 放前面（四个字一个都不认识，反而减分）
- 不要用花体、艺术字写英文（十年后看会很土）
- 不要在一个标题里混三种字号（这是"不高级"最直接的原因）

**发布前必查**：GitHub / Steam / 网盘有没有重名；`岩笋` 与 `Rock Sprout` 的商标有没有被注册。

## 3. 品牌隐喻（笋的三个层次，分别对应产品的三件事）

| 笋的意象 | 对应的产品事实 |
|---|---|
| **破土**（从下往上冒出尖） | 新工具，从零开始，不抄任何人 |
| **层叠**（笋壳一片包一片） | mod 一层层合并进游戏的 pak，装和卸都可逆 |
| **节节长**（一节一节往上） | v0.1 → v0.2 → … → v2.0，一版长一寸 |

## 4. Logo 方向

- **主形**：三层叠加的尖锥（笋壳），底部宽、顶部窄，尖端有一粒光
- **简写**：只留最外层轮廓 + 顶部一点，小尺寸也能认
- **颜色**：雏形用笋白 `#E8DFCB`，尖端一点生长绿 `#8FD48A`
- **禁忌**：不要龙、不要钻头、不要随便堆发光特效——那就变回 MintCat 的味道了

### 4.1 占位图标（临时，2026-10-27 起用）

- **来源**：用户提供的 `下载.svg`（960×300 横行标版：图标 + 「笋」字标 + `SUNSHOOT` + "从岩缝里长出来"）
- **已裁出方形版**：`assets/icon-placeholder.svg`（viewBox `40 40 220 220`）
- **用途**：开发期占位，不作为最终 logo
- **替换时机**：v0.5 视觉统一时重画
- **已定**：占位图里字标写的 `SUNSHOOT` **弃用**，正式英文名固定为 `Rock Sprout`（2026-10-27）。裁出的方形版不含任何文字，可直接使用
- **与规范冲突的地方**（占位期间不管，最终图标要改）：绿色渐变是发光感，和我们定的"哑光不发亮"相反

## 5. 配色

| 色名 | 色值 | 用在哪 |
|---|---|---|
| 岩底 | `#0A0F14` | 页面背景 |
| 岩层 | `#16202A` | 卡片 |
| 岩面 | `#22303D` | 悬浮 / 选中 |
| 笋白 | `#E8DFCB` | 主文字、笋本体色 |
| 生长绿 | `#8FD48A` | 成功、已装、进度 |
| 矿琥珀 | `#F0A93C` | 金币、稀有、主按钮（**这是主色**） |
| 晶蓝 | `#55C8F0` | 链接、次要强调（**只做点缀**） |
| 危红 | `#E2564E` | 错误、删除 |

**关键**：主色是**琥珀**，不是青蓝。青蓝在 MintCat 里是主角，在我们这里只是点缀——一眼就能看出不是同一个东西。

## 6. 字形

- 正文/界面：思源黑体（或系统自带微软雅黑，先不引外部字体）
- 标题：可选用「得意黑」做少量强调（注意授权：SIL OFL，可商用）
- **数字必须等宽**（等级、金币、矿物数要对齐，这是"专业感"的来源）

---

## 7. 形态语言（三条硬规则）

1. **尖不圆**：圆角只给 2–4px。卡片右上角可以做一个 45° 斜切，像破土的尖。MintCat 是圆角卡片，我们从形状上就分开。
2. **哑光不发亮**：不用霓虹辉光，用层叠阴影 + 1px 描边做出岩层厚度。
3. **一级游戏语言，二级人话**：页签名用"矿脉""矿车"这类游戏词，旁边小字用"发现 mod""下载队列"说明。有味道，但不影响新人理解。

---

## 8. 图标

- 线性、1.5px 线宽、**端点斜切**（不用圆头）
- 一套自绘，约 16 个就够：搜索、背包、下载、齿轮、职业、武器、衣架、杯子、唱片、警告、对勾等
- 不用第三方图标库的默认风格（那会立刻变得"很通用"）

---

## 9. 动效

| 场景 | 动的样子 |
|---|---|
| 页面切换 | 从下往上淡入（像升降井上来），200ms |
| 加载 | 一根线从下往上长满（笋冒头） |
| 安装成功 | 顶部一点绿光弹出，不弹窗 |
| 错误 | 轻微左右摇晃 1 次，不做红色闪屏 |

## 10. 布局骨架

```
┌──────────────────────────────────────────────┐
│ 顶部状态带  游戏已识别 · 令牌有效 · v0.1     │
├────────┬───────────────────────┬─────────────┤
│ 导航   │  主内容区             │  详情/预览  │
│ 矿层   │  （列表 / 看板 / …）  │  （可收起） │
│ 随行   │                       │             │
├────────┴───────────────────────┴─────────────┤
│ 状态栏  版本 · 日志 · 报告问题               │
└──────────────────────────────────────────────┘
```

- 主导航在左，两组折叠
- 详情面板在右，可收起（大屏常驻，小屏滑出）
- **不用顶部横向导航**——那会很像常见的 web 后台，也会很像 MintCat

## 12. 组件规范

- **卡片**：岩层底 + 1px 岩面描边 + 右上 45° 斜切（仅大卡）
- **按钮**：主按钮矿琥珀底 + 深色字；次按钮描边；危险按钮只在确认框里出现
- **列表项**：左边缩略图、中间标题/副标题、右边状态徽章
- **进度**：细长条，从下往上"长"的动画，颜色用生长绿
- **空状态**：一句人话 + 一个明确的下一步按钮，不要幽默插图
- **错误**：说清三件事——发生了什么、为什么、现在点哪里

---

## 13. 和 MintCat 的差异（品牌 + 法律双保险）

| 维度 | MintCat | 岩笋 |
|---|---|---|
| 主色 | 全息青蓝 | 矿琥珀 |
| 形状 | 圆角卡片 + 发光 | 尖角 + 哑光 + 层叠 |
| 导航 | 顶部 / 侧栏常规 | 左侧两组、游戏语言命名 |
| 气质 | 科幻面板 | 手工矿具 |
| 定位 | mod 管理器 | 游戏伴侣 |

**这不是"换个颜色避嫌"，是从形状语言和气质上就是另一个东西。**
