# v0.1.7 实施计划

> **依据**：`文档\路线图-v0.1到v1.0.md` §4「v0.1.7 深挖」
> **这一版要做成的三件事**：① 玩家不用自己去装 UE4SS；② 脚本类 mod 能装上并生效；③ 装了 mod 之后，有新版本能一键换掉。

这一版是 mod 主线的最后一块。做完之后，`背包`、`矿脉`、`今天` 三个页面就是完整闭环；再往后才是看板、联机、存档分析那些「伴侣」功能。

## 1. 要做的

### M7-0 先把事实钉死（0.5 天，**必须最先做**）

三件事决定后面怎么走，没做完不动代码：

1. **拉 10–20 个 mod.io 上的 DRG 脚本类 mod，拆包看内容**：`Scripts\main.lua` 占多少、有没有 `main.js` 之类。结论决定 M7-4 做不做 JS。
2. **在 DRG 上实测官方 `override.txt`**：把 UE4SS 核心放进 `Win64\ue4ss\`、根目录只留 `dwmapi.dll`，看 UE4SS 能不能正常加载（看它自己的日志）。决定 M7-2 用子目录还是平铺。
3. **记录 `UE4SS.log` 的关键行格式**：哪一行代表「加载成功」、哪一行代表「没加载」。这是 M7-3 的判据。

**验收**：一份不超过一页的记录，三项各一行结论；不确定的写「未验证」，不许写推测。

### M7-1 下载与校验（1 天）

- 版本号 `v3.0.1`、下载地址、**sha256 写死在代码里**，不接受动态获取
- 5.5 MB 下载要有进度、可取消、失败可重试
- 下载失败或校验不通过 → 给「手动下载」入口 + 一句「下好之后放到这个目录」
- 校验通过后**先解压到临时目录验证结构**（`dwmapi.dll` / `UE4SS.dll` / `UE4SS-settings.ini` / `Mods\` 齐了），再往游戏目录动

**验收**：断网时点「装 UE4SS」→ 出现手动下载入口和路径说明，不出现英文报错。

### M7-2 安装与卸载（2 天）

**装之前的四道检查**，任一条不过就停下说清楚：

1. 游戏没在运行（复用现有 `blocked_by_running_game`）
2. `Win64` 里没有同名冲突：`dwmapi.dll` 若已存在且**不是我们装的**，先走第 4 条
3. 磁盘空间 ≥ 100 MB
4. **检测到已有别的 UE4SS**（例如 `ue4ss\UE4SSL.dll`）→ 弹「这台机器上有一套别的工具装的 UE4SS，要不要换成官方的」，同意后**先备份**（`dwmapi.dll` + `ue4ss\` 目录）再动

**写入流程**：备份 → 写文件 → 逐个校验合并后的状态 → 任一步失败**全部还原**。这套机制 v0.1.1 卸载时已经做过，复用，不写第二套。

**卸载**：按安装时记下的文件清单逐项删；`Mods\` 目录里**用户自己放的东西不盲删**（只删我们登记的条目）。

**验收**：装 → 验 → 卸，`Win64` 目录的字节级快照与装之前一致。

### M7-3 生效检测（1 天）

- 游戏启动后读 `UE4SS.log`，判断最近一次启动有没有「加载成功」那行
- 判据写死，不许模糊匹配一大片
- 结论变成「今天」页的一条：成功不显示；失效显示「UE4SS 没生效，可能是游戏更新了，点这里换版本」
- UE4SS 根本没装时不检测、不显示

**验收**：人为把 `UE4SS.dll` 改名 → 启动游戏 → 「今天」页出现失效提示；改回来 → 提示消失。

### M7-4 脚本类 mod 的安装路径（2 天）

**现在的问题**：`local.rs:237-249` 对「没有 pak 的文件夹」是**整个打成 pak**，所以现在把脚本 mod 丢进来，会被塞进 `mods_P.pak`，装完一定不生效（`integrate.rs` 全程没有内容类型分支）。

- 新增判定：包内含 `Scripts/` 或 `.lua` → 脚本类
- 脚本类**不进 pak 合并**，落到 `ue4ss\Mods\<名字>\`
- 这类 mod 在 `背包` 里要能看出是「脚本类」（避免用户以为它和 pak mod 一样）
- 卸载 = 删那个目录

**验收**：装一个 Lua mod → 目录结构正确、`UE4SS.log` 里有它的加载记录。

### M7-5 mod 一键升级（1.5 天）

- 「今天」页现有的「有新版本」从提示变成「一键换新版」
- 换的时候：删旧 → 装新 → 失败回滚到旧
- 只对 `source = modio` 的 mod 生效，本地导入的不显示

**验收**：真换一次，换完 `file_id` 更新、游戏里能进。

### M7-6 说明、回归、出包（1.5 天）

安装 UE4SS 前的那一次弹窗，三句话定稿：

> 1. UE4SS 是一段注入游戏进程的脚本加载器，装在游戏的 `Binaries\Win64` 里，只影响这台电脑。
> 2. 装好之后，**游戏里的 mod 列表看不见它管的东西**——那是游戏自带的另一套系统。要卸载只能从这个程序里卸。
> 3. 联机：DRG 官方只认它自己那套 mod 体系，注入类的改动不在它的名单里。你想在联机时用不用，自己决定。

Release 说明补三条：游戏内列表看不到是正常的、只能从我们这里卸、UE4SS 是什么。

**回归**：现有 90 场景 + 新增（下载失败 / 校验失败 / 撞名拒装 / 已装 MintCat 版提示 / 脚本类识别 / 脚本类卸载 / 失效检测 / 一键升级）。

## 2. 不做

- **JS 脚本 mod**（MintCat 那套 `UE4SSL.JavaScript`）——不接第三方定制注入器
- **UE4SS 自动更新**——锁版本，只在失效时提示
- **多版本并存**
- **改 `dwmapi.dll` 或维护自己的 UE4SS 分支**
- **汉化脚本 mod 的内容**（v0.1.6 的翻译只覆盖 mod 简介）
- **游戏内列表联动**——那是另一套系统，碰不到

## 4. 风险

| 风险 | 影响 | 处置 |
|---|---|---|
| DRG 上 UE4SS 跑不起来 | M7-3/M7-4 全废 | M7-0 第一件事就验，跑不起来就停，回来重新设计 |
| `override.txt` 在 DRG 上不生效 | 只能平铺 | 退回平铺，多一项卸载要认的文件 |
| mod.io 上脚本 mod 几乎全是 JS | M7-4 没有实际受益者 | M7-0 实测确认比例，若 < 10% 就降级：只做 UE4SS 装卸，脚本 mod 安装推迟 |
| GitHub 下载在国内不稳 | 部分用户装不上 | 手动下载入口 + 明确路径说明 |
| 一键升级把 mod 换坏 | 用户丢装好的 mod | 先删旧再装新之前**留一份旧包**，失败回滚 |
