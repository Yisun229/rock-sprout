## §1 环境现状（已核实，别重复检查）

| 项 | 状态 |
|---|---|
| Hyper-V | 已启用（`HypervisorPresent: True`） |
| 虚拟磁盘默认路径 | `E:\rock-sprout-vm\disks` |
| 虚拟机配置默认路径 | `E:\rock-sprout-vm\configs`（注册表里叫 `DefaultExternalDataRoot`） |
| C 盘剩余 | 约 80.5 GB，启用前后基本没变（说明没有东西落到 C） |
| ISO | `Win11_Enterprise_Eval_26H2_zh-cn_x64.iso`，8,548,628,480 字节（7.96 GiB），已就位 `E:\rock-sprout-vm\iso\`，sha256 `b37a06d5…e667a84` |

**为什么用「企业评估版」而不是消费版专业版**：消费版 ISO 的下载链接是**会话签名**的，命令行拿不稳；企业评估版是微软公开的**静态直链**，同样是干净的原装系统，对「装 / 卸 / 查残留」这件事没有任何影响。评估期 90 天，到期换检查点重装即可。

**当前会话不是管理员**：`Get-VM` / `Get-VMHost` 会报"没有完成此操作所需的权限"。所有 Hyper-V 操作必须在**管理员 PowerShell** 里跑。

## §2 里程碑

### M8.1-0 建虚拟机并打基线检查点

1. 用管理员 PowerShell 建 VM（第 2 代、4 GB 内存、2 vCPU、60 GB 动态扩展盘），`-Path` 与 `-VHDPath` 都显式指向 `E:\rock-sprout-vm\`。
2. 无人值守安装：`autounattend.xml` 塞进 ISO 根目录或挂一个软盘，建本地管理员账号（密码只写本机，**不进仓库**）。
3. 装完打检查点，命名 **`clean-baseline`**。
4. 关掉 guest 的休眠（`powercfg /h off`）与自动更新（避免验证中途系统自己重启）。

**验收**：`Get-VMSnapshot -VMName <名字>` 能看到 `clean-baseline`；`Get-VM | Select Path` 显示在 E 盘；C 盘剩余没掉几十 GB。

### M8.1-1 基线取证（装之前）

记录到 `_tools\v0.1.8.1-干净机验证记录.md`：

1. `%LOCALAPPDATA%` 下是否存在：`RockSprout`、`RockSproutWebView2`、`RockSprout-WebView2`
2. 安装目录默认位置下有没有同名目录
3. 开始菜单、桌面有无相关快捷方式
4. `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\` 下有无相关项
5. 游戏目录（**这台机器上没装游戏**——记下这一点，第 4 步会用到）

**验收**：五项都是"干净"，并且原始输出贴进记录。

### M8.1-2 安装验证

1. 在 guest 里下载 `RockSprout_0.1.8_x64-setup.exe` 与 `SHA256SUMS.txt`，**先核 sha256 再执行**。
2. 装：观察是否有 UAC 弹窗。
3. 查三处：开始菜单快捷方式、桌面图标、`Uninstall` 注册表项。

**验收**：sha256 与 `SHA256SUMS.txt` 一致；三处都出现；无 UAC（`installMode: currentUser`）。

### M8.1-3 首启动与功能

1. 首次打开：落在哪一页、窗口标题、`关于` 里版本号是否为 `0.1.8`。
2. 打开设置页，确认令牌卡片能显示、能粘贴（不用真令牌）。
3. **装一个 mod**：guest 里没有游戏，所以用**本地导入**路径（`导入本地 mod 文件`）验证导入链路；如果这条走不通，记录原因。

**验收**：三项都对；导入路径要么成功、要么有明确的人话错误，不许白屏或静默失败。

### M8.1-4 卸载与残留（本版核心）

卸载后逐项判定，**必须分清"该留的"和"该清的"**：

| 项 | 期望 | 为什么 |
|---|---|---|
| `%LOCALAPPDATA%\RockSprout\data\` | **保留** | 数据保留是设计，卸载不动你的 mod 与令牌 |
| 安装目录本体 | **清掉** | 程序文件不该留 |
| 开始菜单 / 桌面快捷方式 | **清掉** | — |
| `Uninstall` 注册表项 | **清掉** | — |
| WebView2 缓存目录（`RockSproutWebView2` 等） | **清掉** | v0.1.3 起卸载钩子会清浏览器缓存 |
| 安装时选的游戏目录 | **不动** | 这台机器没装游戏，无此项 |

**验收**：六项逐条给出"实际 vs 期望"，有偏差的单独标出来。

### M8.1-5 便携包

在 guest 里把 `RockSprout_0.1.8_portable_win64.zip` 解压到 `D:\sprout-portable\` 跑一次，确认：

1. 双击能起，不要求安装
2. 数据落在 exe 旁边的 `data\`（不是 `%LOCALAPPDATA%`）
3. 拔掉/重命名 `data\` 后能自动重建

**验收**：三条都成立；`data\` 路径要在记录里写明。

### M8.1-6 修问题 + 出包发布

1. 把 M8.1-1 ~ M8.1-5 里发现的偏差列成表，逐条修。
2. 回归 + 单测必须仍然全绿（改了就重新跑）。
3. 版本号四处（含 `Cargo.lock` 自身条目）改 `0.1.8.1`。
4. 出包、算 sha256、上传后从服务端核 digest。
5. 发布说明写明：**已在 Windows 11 企业评估版 26H2（简体中文）干净虚拟机上验证**，并列出验证项与已知限制。

**验收**：发布说明里的"已验证"有对应的验证记录文件支撑；没有记录支撑的话不许写。

## §3 边界

- **不夹带新功能**，只修验证发现的问题
- **干净机里不装任何开发工具**（无 Rust、无 Node、无 VS）；它模拟的是普通用户
- 回归与单测在改动后必须重新全绿
- **ISO 与虚拟机不进仓库**：`D:\AI_Workspace` 与 `E:\rock-sprout-vm` 都不在 git 里，别手滑 `git add`
- guest 密码只存本机，不许写进任何文档或提交

---

## §4 明确不做

- 不做多系统验证（只需一套 Windows 11）
- 不验证真实游戏环境（这台机器没有《深岩银河》；那条留给有人真机试用时再补）
- 不做安装包静默参数（`/S`）的正式支持，只顺带观察
- 不为验证加自动化框架（手写脚本即可）

## §6 风险

| 风险 | 应对 |
|---|---|
| 无人值守安装失败，卡在语言/OOBE 界面 | 先手装一台确认能过，再固化 `autounattend.xml`；失败就退回手动装（多花 15 分钟） |
| PowerShell Direct 进不去 guest | 检查 guest 里是否有本地管理员、是否启用了 PowerShell；实在不行退回"人工在 guest 里跑脚本" |
| 评估版 90 天后过期 | 检查点重装；ISO 留着不删 |
| guest 里没有游戏，装 mod 走不通 | 用本地导入验证导入链路，并在记录里明确写"游戏内生效未验" |
| 干净机验证出一堆问题，把 2.3 天拖长 | 修不完的写进 v0.1.9，但**残留判定那六项必须这一版结清** |
