## §0.5 本版明确不做

- **不做 mod 详情页的评论/订阅/收藏**——mod.io 那几组接口这版不碰。
- **不做封面图本地缓存**——直连 CDN，失败就占位，不落盘。
- **不做翻译的语言自动识别**——源语言固定按 `en` 请求。
- **不改 30 个命令的现有签名**——只新增，不改旧的。
- **不动视觉基调**——不加新配色、不改圆角/间距体系；面板和下拉沿用现有 token。

## §1 事实底稿

### 1.1 代码坐标（改之前先看这几处）

| 位置 | 现状 |
|---|---|
| `app/src-tauri/src/modio.rs:83-89` | `ModSummary { id, name, summary, downloads }`——**只有 4 个字段** |
| `app/src-tauri/src/modio.rs:91` 起 | `ModDetail { id, name, summary, description, downloads }`——**没有封面、作者、更新时间、标签** |
| `app/src-tauri/src/modio.rs:32-44` | `ApiError { Unauthorized, Forbidden, NotFound, RateLimited{retry_after}, Network, Decode }` |
| `app/src-tauri/src/modio.rs:290` | `latest_file(url, bearer)`——v0.1.5 加的，按 file_id 比新版 |
| `app/src-tauri/src/ipc/mods.rs:493` 起 | `search_mods` 的 `query` 与 `_sort=-date_added` 都**写死在 URL 里** |

| `app/src/pages/MineVein.tsx:51-52` | `ROW_HEIGHT = 72`；行 `onClick` 目前是 `null`（**点行没反应**，这是本版要补的） |

| `app/src/api.ts` | 全部走 `invoke`，**前端没有一处 fetch** |
| `app/src-tauri/src/cache.rs` | `Fresh<T>` 无 TTL |

### 1.2 mod.io 实探结果（2026-10-30 实测，不是推断）

- `GET /games/2475/mods?q=...&_sort=-date_added` 需要令牌，无令牌一律 401。
- 封面四档现成：`logo.thumb_320x180` / `thumb_640x360` / `original` / `filename`——**不用自己裁图**。
- 作者：`submitted_by.username`；更新时间：`date_updated`。
- 简介正文：`description_plaintext`（纯文本，比 `description` 的富文本好处理）。
- 标签：`tags` 是按组分好的对象，共 5 组；**Type 组 9 个值**（Weapon / Build / Gameplay / Visuals / Enemy / Loadout 等）。
- 筛选参数 `?tags=` 实测可用：按 `Weapon` 过滤命中 46 条，结果正确。
- **`_sort` 必须带下划线**：写 `sort` 不生效，且写错字段名也返回 200——不能只看状态码，要看结果顺序。

### 1.3 Google 免费翻译端点实探（2026-10-30 实测）

| 项 | 结果 |
|---|---|
| 端点 | `GET https://translate.googleapis.com/translate_a/single?client=gtx&sl=en&tl=zh-CN&dt=t&q=<编码后文本>` |
| 短文本 | 200，0.63 秒，375 字节，正确译出 |
| 长文本 3,400 字符 | 200，0.95 秒，URL 4,785 字符仍可用，返回 50 段 |
| 返回结构 | `[[[中文, 原文, ...], [中文, 原文, ...]], null, "en", ...]`——取 `[0]` 数组，把每段的 `[0]` 拼起来 |
| 分块验证 | 按句切、每块 ≤1500 字符，1812 字符切成 1488 + 324 两块，边界正确 |
| 需要 key | 不需要 |

**结论**：客户端按句分块（≤1500 字符）逐块 GET，不用 POST，避开 URL 长度风险。

## §2 阶段

### M6-0 基线（0.5 天）

- `node _tools/check-all.mjs --ui-snap before` 截四页到 `_tmp/ui-baseline/before-016/`。
- `node _tools/perf-baseline.mjs "v0.1.6 改造之前"` 追加一段。
- 用一次性脚本打 5 个真实请求，把详情字段名再核一遍（防我记错）。
- **产出**：基线截图 + 性能段 + 字段核对记录。**不通过就不往下做。**

### M6-1 后端：详情补字段 + 筛选参数 + 翻译（2 天）

**a. 详情字段**（`modio.rs`）

`ModDetail` 增加：`logo_320`、`logo_640`、`creator`（`submitted_by.username`）、`date_updated`、`description_plaintext`（缺失填空串），`tags` 改成 `Vec<String>`（只取 Type 组的值）。
命令签名不变，只在反序列化层补字段。

**b. 筛选参数**（`ipc/mods.rs`）

新增 `list_mods(keyword: Option<String>, tags: Vec<String>, version: Option<String>, sort: String) -> Result<Vec<ModSummary>, String>`。
`search_mods` 保留原签名，内部改为调 `list_mods`（避免两套拼 URL 的代码）。
`sort` 只接受三个值：`relevance`（不带 `_sort`）、`latest`（`_sort=-date_added`）、`downloads`（`_sort=-downloads`）。

**c. 翻译**（新文件 `src-tauri/src/translate.rs`）

- `pub async fn translate(text: &str, target: &str, endpoint: &str) -> Result<String, TranslateError>`
- 分块：按 `[^.!?]+[.!?]+\s*` 切，每块 ≤1500 字符；单句超长时硬切兜底。
- 逐块串行请求，按顺序拼接。
- 错误分五类：`Unauthorized`（401/403）、`RateLimited`（429，读 `Retry-After`）、`Network`、`Decode`、`TooLong`（原文 >10000 字符直接拒，不发请求）。
- 缓存：`cache\zh\<mod id>-<sha256 原文前 16 位>.json`，内容 `{source_hash, target, text, translated_at}`。命中直接返回，不发请求。

**d. 新命令**（只新增，不改旧的）

- `translate_detail(mod_id: u64, target: String) -> TranslateResult`
- `translate_text(text: String, target: String) -> String`
- `get_settings` / `set_settings` 扩两个字段：`translate_endpoint`（默认上面那个 Google 地址）、`translate_target`（默认 `zh-CN`）。

### M6-2 前端：抽屉预览（1.5 天）

- `MineVein.tsx` 行 `onClick` 改为打开面板；勾选框加 `stopPropagation`。
- 新组件 `components/ModPreview/`：
  - shell 布局：`App.tsx` 里窗口宽度 ≥1000px 时变三栏 `160px 1fr 360px`；<1000px 时面板改成覆盖在列表上的浮层（带遮罩）。
  - 内容顺序：封面 → 名字 → `下载量 · 作者 · 更新时间` → 标签（最多 6 个，多出显示 `+N`）→ 简介（折叠 4 行）→ 安装按钮。
  - 关闭：Esc、右上 ×、再点同一行。
  - 打开时先出骨架块，数据到了再填充。
- 约束：`appStore.tsx` **只加** `previewModId: number | null` 和一个 action，不许重构 reducer。

### M6-3 前端：筛选（1 天）

- 搜索框右侧并排三个下拉：类型（多选，9 个值，本地常量表）、版本、排序。
- 状态进 `appStore` 的 `filters`；任一项变化即重新请求，沿用现有 300ms 防抖。
- 请求参数拼进 `list_mods`。

### M6-4 前端：翻译（1.5 天）

- **行内**：每行右侧一个「译」图标按钮（`stopPropagation`）。点击翻 `summary`，就地替换成中文，下方小字保留原文。
- **面板**：简介区右上角「翻译」按钮 → 双语对照（原文段 + 中文段交替）。已缓存则直接显示。
- **底部栏**：选中 ≥1 时出现「翻译选中（N）」，上限 10、并发 2、间隔 400ms，进度显示在底部栏。
- **失败**：行内图标变灰 + 悬停显示原因；面板显示「翻译失败，点重试」。

### M6-5 空态与细节（0.5 天）

- `description_plaintext` 为空 → 面板里显示「作者还没有写简介」，**不显示翻译按钮**。
- 封面加载失败 → 占位色块（`--rock-face` 底 + 名字首字）。
- 标签一个都没有 → 整行不占位，不显示空标签区。

### M6-6 验收与出包（0.5 天）

- 回归：82 条 → 目标 **≥ 92**（新增 10 条，见 §3）。
- 单测：119 条 → 目标 **≥ 129**。
- 性能：冷启动仍 <1.5 秒；装一个 mod 不比 v0.1.5 的 703ms 慢超过 10%。
- 出 setup + portable，算 sha256，写「实际做了什么」给计划侧。

**合计 7.5 天。**

## §3 验收单

做到下面这些才算完：

1. **点行开面板，勾选不开面板**——两个手势互不干扰。
2. **面板八项齐全**：封面用 `thumb_640x360`；断网时显示占位色块不显示裂图。
3. **简介为空的 mod**：显示「作者还没有写简介」，且没有翻译按钮。
4. **筛选**：选 2 个类型 + 关键词 + 按下载量排序，用真实 mod.io 验一次，结果与请求参数对得上。
5. **翻译**：行内翻 1 个成功；批量翻 10 个成功；第二次点同一个**不发请求**（用假代理拦一次证明缓存命中）。
6. **断网**：翻译报「翻译失败，点重试」；其余页面不受影响。

新增回归 10 条：面板开关 3 条（点行/Esc/再点）、筛选 2 条、翻译缓存 2 条、简介为空 1 条、断网降级 1 条、语言切换不影响 1 条。

## §4 风险与对策

| 风险 | 对策 |
|---|---|
| Google 免费端点随时可能改或封 | 设置里留自填入口；出问题时给出明确提示而不是"网络错误" |
| 免费端点无承诺，批量可能吃 429 | 已限并发 2、间隔 400ms；429 单独提示并给「稍后重试」 |
| 抽屉并列挤压列表（1100 窗口下列表只剩约 580px） | 三列表格在窄栏时隐藏「下载」列，只留名字和摘要 |
| 详情要多一次请求 | 只在打开面板时取，列表页不预取 |
| 翻译把 mod 名也翻掉（专有名词） | 只翻简介和摘要，**名字永远不翻** |
