## 0. 这份路线图怎么排的

两条依据，**冲突时第一条优先**：

1. **玩家能不能感觉到变好** —— 每个版本必须带来一次看得见的变化
2. **做了不返工** —— 技术依赖顺序

每个版本必须回答三件事，缺一件就不算完成：

- 一句话目标
- **这个版本比 MintCat 强在哪**（写不出来，这个版本就不做）
- 周期

### 维护规矩（每次写版本计划时，同一轮做完）

1. **计划写完，同一轮就改路线图对应那节。** 不允许"文档说 3 条、手上做 6 条"
2. **发现某功能提前做了，两个方向都要留痕：**
   - 在**实际做到的版本**里写 `✅ xxx（原定 vX.Y 提前完成）`
   - 在**原定版本**里把那条改成 `→ 已由 vX.Y 提前完成`
3. **每版结束时回填 §2 的"实际"列**：实际周期、实际做了什么
4. **新版本开工前，先扫一遍后面版本的功能清单**，确认没有重复排期、或者排了但已经提前做完的

## 3. v0.1 分成两半

上一版把这两半混在一起了。分开之后你可以自己决定要不要。

### 3.1 核心（你要的，必须有）

- 搜 mod、看详情
- 装、卸、启用/停用
- 启动游戏
- 令牌粘贴 + 自动校验
- **视觉定调**：配色、形态、页签名、空状态文案

### 3.2 基建（我认为该有，但可延后 —— 等你拍板）

| 项 | 我认为的理由 | 延后到哪 |
|---|---|---|
| 本地缓存 | 断网时还能看到列表、能卸载 | v0.2 |
| 导出 / 导入配置 | 换机器不用重装一遍 | v0.2 |
| 报告问题按钮 | 用户说不清问题，你就没法修 | v0.4 |
| 三段式失败提示（401 / 429 / 断网） | 泛泛的"网络错误"等于没提示 | v0.2 |

**建议**：前三项延后没问题，**失败提示建议留在 v0.1**——这是唯一会直接导致"装了没用"的东西。

### v0.1 能装（6–9 周）· ✅ 已交付

### v0.3 敢用（3–4 周）

> 第三次改版（2026-10-28）：原文三条里"快照原 pak"是错的。原 pak 有 2.4 GiB 且全程只读，
> 备份它没有意义；真正的风险是合并包写到一半被写废。以下按六问质询结论重写。

- **合包原子写**：先写 `.tmp`、重读校验，再三步换名。不做这一条，"救回来"无从谈起
- **快照 + 一键回滚**：快照对象是 `mods_P.pak` + 记账目录，**不是**原 pak
- **卸载残留检查 + 记账对账**：记录在但文件没了 → 列表标灰，可"只删记录"
- **游戏更新检测**：原 pak 指纹变了就提示重建，并禁用撤销
- **游戏运行中拦截**：装 / 卸 / 撤销前查进程，有就拦住
- **陌生产物提示**：游戏目录里不认识的 pak，提示并可移到备份目录

### v0.4 轻便（2–3 周）
- 绿色版打包 → **「配置跟文件夹走」已由 v0.1 提前完成**（`paths.rs`），本版还差：出压缩包 / 安装包两种形态
- 启动计时优化、搜索优化

## 7. 音乐播放器的红线

DRG 的 OST 是 Ghost Ship Games 的商业音乐，音乐版权独立于游戏版权。

- **不能做**：把 OST 打进安装包、从游戏目录提取音频分发、"一键下载官方音乐"
- **能做**：跳转官方页面（Steam 音乐 / Spotify / Bandcamp）、播放用户自己拥有的音频文件
- **注意**：多数平台不允许第三方内嵌播放，所以多半只能做"跳转"

## 8. 存档解析的维护成本

游戏一更新，存档结构可能变，面板会坏。这是长期的、躲不掉的承诺。

把成本压到最低的五个设计：

1. **只读不写** —— 坏了只是数字不对，不会毁档
2. **按字段名读，不按偏移量读** —— 游戏加字段不影响老字段
3. **缺字段就跳过** —— 某个面板解析失败就整块隐藏，不弹错
4. **解析器独立成模块** —— 和 mod 主线解耦，它坏了不影响装 mod
5. **版本表** —— 记录"哪个游戏版本 / 哪个存档格式 / 哪些字段"

## 10. 明确不做

- 多游戏架构
- 云备份 / 云同步（改成本地导出导入）
- 自维护 mod 镜像清单
- 付费、广告、统计上报
- 需要租服务器的任何东西
- 写存档（只读）
- 用 MintCat 的任何代码、图标、名称

## 11. 难题攻克顺序

1. **M0 生死关卡**：mint 能不能编出来、能不能装一个 mod 进游戏生效
2. 令牌换成真 uid（摆脱限速）
3. Tauri 外壳 + 安装流水线接线
4. 搜索 / 详情 / 安装页
5. 视觉调子落地
6. 存档解析地基（v1.1）
7. 各面板逐个搭（v1.2–v1.6）
