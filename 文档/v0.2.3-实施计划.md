# v0.2.3 实施计划（装备定制·下：超频 / 皮肤 / 十字镐 / 喷漆）

> **依据**：`文档/路线图-v0.1到v1.0.md` §4「v0.2.3 装备定制（下）：模组 / 皮肤 / 十字镐 / 喷漆」

| # | 决策 | 内容 |

## §2 存档里这四类数据（已确认，来自 `_tools/save-fields.md`）

| 数据 | 字段 | 实测 |
|---|---|---|
| 已得超频（图纸） | `SchematicSave.ForgedSchematics`（已锻造）/ `OwnedSchematics`（已得未锻造） | 50 + 10 = **60** |
| 装着的超频 | `ItemUpgradeLoadouts[i].Loadout{武器}.EquippedOverclock` | 全 0 = 没装 |
| 超频是否解锁 | `…Loadout{…}.OverclockingUnlocked` | 本机实测**都是 false** |
| 物品皮肤 | `UnlockedItemSkins`（Map：物品 GUID → `{Skins: Set}`） | **25** 个物品有皮肤 |
| 装着的皮肤 | `…Loadout{…}.EquippedSkins` / `EquippedSkinColor` / `EquippedSkinMesh` | — |
| 外观件 | `CharacterSaves[i].Vanity.UnLockedVanityItemIDs` | 48 / 49 / 47 / **117** / 0 |
| 十字镐部件 | `UnlockedPickaxeParts`（Set） | **19** 个 |

**注意两处与直觉不符的地方**（写进验收，不许想当然）：
1. **超频的「已获得」不是 `PurchasedItemUpgrades`（那是模组 124 个），而是图纸（Schematic）**——完成事件/深潜拿到图纸，锻造后成为超频。本机 60 个。
2. **十字镐不是「六个格子」，是 19 个已解锁部件**；存档里有没有「当前装的是哪几个」这一层，M0 要确认，没有就只列已解锁、不显示当前装配。

## §3 里程碑

### M0 · 名字表（0.5 天）
- 从 `_tools/_pak/` 抽四张表：超频（目标 ~120 条全量）、皮肤、外观件、十字镐部件；名字走 `pylocres` 那套键→stringIndex join
- **先确认两件事**：① 超频总表能不能抽全（抽不到就只列已获得的 60 条）；② 十字镐的「当前装配」在存档哪个字段（找不到就放弃这一层）
- 产物：`app/src/data/overclocks.json` / `skins.json` / `vanity-names.json` / `pickaxe-parts.json`
- 验收：每张表逐条报「抽出 N / 期望 M / 缺 K 条及原因」，不许只报总数

### M1 · 超频（0.5 天）
- 武器抽屉加「超频」分段，按武器分组，标「已获得 / 未获得 / 正装着」
- 降级：总表抽不到 → 只列该武器已获得的，标题写「已获得 N 条」
- 验收：指定一把枪，对照存档数出已获得条数，界面一致

### M2 · 皮肤与喷漆（0.75 天）
- 抽屉加「外观」分段：列出该武器/护甲的皮肤，已拥有的可看图（图片砍掉，本版只列名字），未拥有的灰掉
- 降级：皮肤名字抽不全 → 只列已拥有的
- 验收：本机 25 个有皮肤的物品，逐个点开能列出皮肤名

### M3 · 十字镐（0.5 天）
- 装备页底部一块「十字镐」：19 个已解锁部件按类别分组显示；有当前装配就标出来
- 验收：与存档 19 个逐个对得上

### M4 · 回归与出包（0.5 天）
- 回归至少 5 条新场景 + 版本号 0.2.3 四处 + 安装包与便携包 + 发布说明
- 验收：默认跑法全过；三句话如实写进发布说明（见 §4）

**合计 2.75 天**（决策 5：超 3 天就砍 M2 的未拥有展示）

## §4 不做

- 皮肤**图片**（要解贴图资源，另开一版）
- 超频的**数值效果**（要解游戏平衡数据）
- 外观的**全套预览图**
- 任何写存档的能力

## §5 风险

| 风险 | 触发条件 | 应对 |
|---|---|---|
| 超频总表抽不全 | pak 里没有独立的超频资产 | 降级只列已获得 60 条 |
| 皮肤名走 locres 键缺失 | 部分皮肤用硬编码名 | 该条显示「名字取不到」并计数 |
| 十字镐当前装配读不到 | 存档无此字段 | 只列已解锁，不显示装配 |

## §6 发布说明必写三句

1. 皮肤目前只显示名字，没有图片；
2. 未获得的超频/皮肤是否列出，取决于名字表抽全没有，以实际行为为准；
3. 十字镐只列已解锁部件，（如果 M0 没找到当前装配）不显示当前装的是哪几个。
