> **编号说明**：v0.1.3，原编号 v0.4（2026-10-28 统一改编号）。
>

## 2. 阶段

### V3-M0 · 量两件事（1 小时）

**改哪**：`_tools/perf-baseline.mjs`

1. 现有的冷启动测量之后加一段：进程起来等 5 秒和 30 秒，各跑一次
   `tasklist /FI "IMAGENAME eq rock-sprout.exe" /FO CSV`，读 WorkingSet，写进基线文件。
2. **新增一项测量**：装 `_tools/fixtures/small-mod.zip`，从点击安装到界面显示"可以启动游戏"的耗时。
   跑三次取中位数，写法参考现有的冷启动测量。

**顺带改一句话**：如果合并阶段现在只有进度条没有文字说明，加一行
「正在合并数据包，装的 mod 越多这一下越慢」。玩家对"知道在干嘛"的容忍度，比"不知道在等什么"高一倍。

**判定**：空闲内存稳定态 < 150 MB 即达标。装 mod 耗时只记录、不设目标——这一版不改合并算法。

### V3-M1 · 便携 zip 产物（3 小时）

**新增**：`_tools/make-portable.sh`

1. 从 `_tools/target/release/rock-sprout.exe` 取主程序
2. 建临时目录 `_tools/_portable/`，放 `RockSprout.exe`、`使用说明.txt`、`data\.keep`
3. 打成 `_tools/release-renamed/RockSprout_<ver>_portable_win64.zip`
4. 算进 `SHA256SUMS.txt`

**使用说明.txt 内容**（四行，不写教程）：

```
解压放到任意可写位置（U 盘、桌面、D 盘都行），双击 RockSprout.exe。
配置、缓存、令牌都在同目录的 data\ 里，整个文件夹拷走就能换机器。
不要放在 Program Files 这类需要管理员权限的目录，否则数据会改存到用户目录。
如果提示缺少 WebView2，按弹窗给的链接装一下再运行（Windows 10/11 通常自带）。
```

**为什么不用 Tauri 的 portable target**：Tauri 2 没有这个 target，官方做法就是自己打 zip。

### V3-M1b · WebView2 自检（1 小时）

**问题**：Tauri 的 exe 不自带浏览器内核，靠系统的 WebView2 Runtime。安装版有 NSIS 兜底，**便携 zip 没有**——目标机器缺 WebView2 时双击就是白屏或英文错误框。

**改哪**：`app\src-tauri\src\main.rs`（在 `tauri::Builder` 建立之前）

1. 读注册表，两条路径任一有值即可：`HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}\pv` 与对应 `HKCU` 路径
2. 都没有 → 弹一个原生对话框（`MessageBoxW` 或 `rfd` 都行，避免为这个引依赖，用 `windows` crate 已有的能力）：

   > 这台机器缺少 WebView2 运行库，岩笋打不开界面。
   > 点确定去下载安装，装完再双击 RockSprout.exe。

3. 确定后打开 `https://go.microsoft.com/fwlink/p/?LinkId=2124703`，然后退出进程

**不做**：不在 zip 里塞 `WebView2Setup.exe`。为罕见场景把包撑大 30%，和"轻巧"打架。

### V3-M2 · 数据目录健壮性（4 小时）

**现在的问题**：`paths.rs:8-18` 只做了一件事——看 `ROCK_SPROUT_DATA`，没有就取 `<exe>\data`。**它不检查这个目录能不能写。** 装在 `Program Files` 里的话，第一次写文件就失败，而报错里不会出现"没有权限"。

**改法**：

1. `paths.rs` 加 `pub fn writable_data_root() -> (PathBuf, DataMode)`：
   - 依次试 `ROCK_SPROUT_DATA` → `<exe>\data` → `%LOCALAPPDATA%\RockSprout\data`
   - 每个位置试写 `.write-test`，能写就用它，删掉测试文件
   - 返回实际位置 + 模式（`portable` / `env` / `fallback`）
2. 新增命令 `data_location`：返回实际路径、模式、是否便携
3. 设置页最上方加一行常驻提示，仅在 `fallback` 模式下显示"便携模式未生效，数据在这里：…"，带"打开文件夹"按钮
4. `diagnostics` 输出里加一行数据目录

**不做**：不弹对话框让用户选位置。`ROCK_SPROUT_DATA` 已经能覆盖高级用户的需求。

---

### V3-M2b · 旧数据识别与迁移（3 小时）

**为什么有这一项**：改安装器模式、以及数据可能落在不同位置之后，装过 0.1.0–0.1.2 的人，数据可能在旧目录里，而新版本读的是空目录。用户会以为"我的 mod 全没了"。

**候选扫描位置**（按顺序）：

1. `%LOCALAPPDATA%\RockSprout\data`
2. `%LOCALAPPDATA%\Programs\RockSprout\data`
3. `%PROGRAMFILES%\RockSprout\data`
4. `%PROGRAMFILES(x86)%\RockSprout\data`

**判据**：目录里存在 `mods\installed\` 且里面有 `*.json`，或存在 `modio-token.txt` —— 才算"真数据"，空目录不算。

**UI**：当前数据目录为空、且扫到候选时，设置页顶部出现一张一次性卡片：

> **发现旧版本的数据**
> 位置：`C:\Users\…\RockSprout\data`（v0.1.2，3 个 mod，1 份快照）
> 要不要沿用？沿用会把它复制到现在的数据目录，原位置不动。
> [沿用] [不用，从空的开始]

**沿用动作**：

1. 把当前数据目录（如果非空）复制成 `data.bak_<时间戳>` 留底
2. 整目录复制旧数据过来
3. 写一个 `data-adopted.txt`（记录来源路径与时间），用于**不再重复提示**
4. `按 [不用]` 也写这个文件，写 `declined`

**注意**：不搬文件、不改旧目录，只复制。用户想回退，删掉当前 `data\` 再从 `data.bak_*` 还原即可。

### V3-M3 · 安装器改当前用户（1 小时）

**改哪**：`app\src-tauri\tauri.conf.json:26-35`

```json
"bundle": {
  "active": true,
  "targets": ["nsis"],
  "windows": {
    "nsis": { "installMode": "currentUser" }
  },
  "icon": [ ... ]
}
```

**效果**：安装不弹 UAC；装到 `%LOCALAPPDATA%`；数据目录一定可写，M2 的回退逻辑在安装版上不会被触发。

**验证**：装一次，确认无管理员提示；确认数据落在安装目录的 `data\`。

### V3-M5 · 瘦身实测（1.5 小时）

**改哪**：`app\src-tauri\Cargo.toml` 末尾

```toml
[profile.release]
lto = "thin"
strip = "symbols"
codegen-units = 1
```

**刻意不写 `panic = "abort"`**：它会让崩溃不产生回溯信息，对一个还需要靠用户报错误的工具是反向优化——省下的体积换掉的是排障能力。

**量什么**：改前改后各记一次——exe 体积、安装包体积、冷启动时间。

**回退条件**：冷启动变慢超过 20%，或构建时间涨到不可接受（> 3 分钟），就去掉 `lto` 只留 `strip`。

## 6. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| WebView2 注册表键在个别精简系统上位置不同 | 自检误报"缺失" | 两个根键都查；查不到时**不阻塞启动**，只记日志 |
| 旧数据扫描误把别的程序目录当数据 | 用户看到莫名其妙的重用提示 | 判据收紧到"有 `mods\installed\*.json` 或 `modio-token.txt`"，扫不到就不提示 |
| 沿用旧数据时磁盘空间不够 | 复制中断，数据半残 | 复制前检查可用空间；失败则回滚到 `data.bak_*` |
| 改 `installMode` 影响已装用户的升级路径 | 老用户可能装出两份 | 现在用户极少；发布说明写"先卸旧版" |
| 便携 zip 被杀软/浏览器误报 | 用户不敢用 | 无签名必然如此；说明里写"未签名，SmartScreen 提示点'仍要运行'" |
| `%LOCALAPPDATA%` 回落被当成"偷偷写 C 盘" | 观感上违背宗旨 | 设置页常驻提示 + 诊断信息写明，不藏着 |
| LTO 拉长构建时间 | 发版变慢 | 回退条件写在 M5 |
